关于我

本科在华中科技大学读通信工程，2025 年起在本校读电子信息专业硕士。

我感兴趣的是让系统在真实世界里跑起来：无人机怎样在未知环境里自己找路、协同、完成任务，以及大模型 Agent 怎样可靠地接进这些系统。这里记录我的研究、工程笔记和踩过的坑。

研究方向

  • 无人机/机器人系统自主探索、多机协同，以及从仿真到实机的部署。
  • 大模型 Agent 工程化把 Agent 接入真实的软硬件系统：工具调用、任务编排和运行可靠性。
